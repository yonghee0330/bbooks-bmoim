나만의 모임 페이지

공유용 링크, 카톡·인스타 미리보기, 구글 검색용 정보까지 자동으로 만들어져요.

신청·입금 관리

신청 접수와 입금 확인, 알림톡 안내는 비북스가 맡아요.

실시간 신청 현황

호스트 전용 비공개 링크로 신청 인원과 입금 상태를 언제든 확인하세요.

함께 홍보

비모임 월간 라인업, 인스타 카드, 매장 QR로 함께 알립니다.

진행 순서

  1. 개설 신청아래 양식을 보내 주세요.
  2. 일정·공간 협의담당자가 연락드려 세부 사항을 정해요.
  3. 포스터 제출아래 규격에 맞춰 보내 주세요.
  4. 페이지 오픈공유 링크와 호스트 현황 링크를 드려요.
  5. 모임 · 정산모임을 진행하고 참가비를 정산해요.

공간 이용료는 대관 페이지의 요금을 참고해 주세요.

포스터 제출 가이드

포스터는 호스트님이 직접 만들어 주세요. 아래 규격에 맞추면 목록·상세 페이지·인스타 카드에 모두 같은 모양으로 깔끔하게 들어갑니다.

크기

글자 크기

제목 · 분위기 · 호스트 중심으로. 날짜·가격·장소는 페이지가 글자로 따로 보여 주니 포스터에 없어도 괜찮아요
