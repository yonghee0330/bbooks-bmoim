# 비모임 v2 백엔드 설정 (Apps Script + 알림톡 + 메일)

> 운영 중인 기존 시트·스크립트는 그대로 둡니다. **테스트용 새 스프레드시트**를 하나 만들어 연결하세요.
> `data/site.json`의 `apiUrl`이 비어 있는 동안에는 페이지가 **테스트 모드**로 돌아가며 아무것도 전송하지 않습니다.

## 1. 스프레드시트 만들기
1. 구글 드라이브 → 새 스프레드시트 → 이름 `비모임 v2 (테스트)`
2. **공유 설정은 "제한됨"** 그대로 두세요. (기존 시트처럼 "링크가 있는 모든 사용자"로 열면 신청자 이름·연락처가 노출됩니다)
3. 확장 프로그램 → Apps Script → 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 통째로 붙여넣기 → 저장
4. 스프레드시트를 새로고침 → 상단에 생긴 **비모임 ▸ ① 시트 탭 만들기** 실행 (권한 승인)
   → `신청` `대관` `개설신청` `호스트링크` `발송로그` 탭이 생깁니다.

## 2. 스크립트 속성
Apps Script → 프로젝트 설정(⚙) → 스크립트 속성 → 아래 값 추가

| 키 | 예시 | 필수 | 설명 |
|---|---|---|---|
| `SITE_URL` | `https://moim.bbooks.co.kr/v2` | ✅ | 알림톡·메일 속 링크 주소 |
| `CATALOG_URL` | `https://moim.bbooks.co.kr/v2/data/catalog.json` | ✅ | 서버가 정원·금액·마감을 직접 확인 (조작 방지) |
| `OPERATOR_EMAIL` | 운영자 메일 | ✅ | 신청·대관·취소요청·개설신청 알림 수신 |
| `BANK_TEXT` | `카카오뱅크 7942-33-45474 (예금주 경규환)` | ✅ | 알림톡·메일 입금 안내 |
| `PAY_DEADLINE_HOURS` | `24` |  | 입금 기한 (기본 24시간) |
| `STORE_ADDRESS` | `경기도 부천시 …` |  | 메일 하단 주소 |
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | 솔라피 콘솔에서 발급 | 알림톡 | 없으면 알림톡은 건너뛰고 메일만 발송 |
| `SOLAPI_PFID` | 카카오 채널 연동 ID | 알림톡 | |
| `SOLAPI_SENDER` | `0321234567` | 알림톡 | 솔라피에 등록된 발신번호 (대체 문자용) |
| `TPL_APPLY` `TPL_PAID` `TPL_RENT` `TPL_RESEND` | 템플릿 ID | 알림톡 | 아래 5번 템플릿 검수 후 입력 |
| `SMS_FALLBACK` | `Y` |  | 알림톡 실패 시 문자로 대체 발송 (기본 Y) |

> API 키는 스크립트 속성에만 넣으세요. 코드·깃허브·페이지에는 절대 넣지 않습니다.

## 3. 웹 앱 배포
1. 배포 → 새 배포 → 유형 **웹 앱**
2. 실행 사용자: **나** / 액세스 권한: **모든 사용자**
3. 배포 URL(`https://script.google.com/macros/s/…/exec`)을 복사해 `data/site.json`의 `"apiUrl"`에 붙여넣기
4. `python3 build.py` 다시 실행 → 테스트 모드 띠가 사라지면 실제 연결된 상태입니다.
5. 코드를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다.

## 4. 트리거 (자동 처리)
Apps Script → 트리거(⏰) → 트리거 추가

| 함수 | 이벤트 | 하는 일 |
|---|---|---|
| `onStatusEdit` | 스프레드시트에서 → **수정 시** | `신청` 탭 `상태`를 **입금확인**으로 바꾸면 참가 확정 알림톡·메일 발송 |
| `expireUnpaid` | 시간 기반 → **1시간마다** | 입금 기한이 지난 `입금대기`를 `취소(미입금)`으로 바꿔 자리를 되돌림 |

### 상태 값 규칙 (`신청` 탭)
`입금대기` → `입금확인` (확정 알림 발송) / `취소요청` (참가자가 요청) → 환불 처리 후 `취소`
- `취소`로 시작하는 상태는 인원 집계에서 빠집니다.

## 5. 카카오 알림톡 (솔라피 기준)
1. **카카오톡 채널** 개설 (비즈니스 채널 인증 권장) — 기존 비북스 채널이 있으면 그대로 사용
2. [솔라피](https://solapi.com) 가입 → 발신번호 등록 → 카카오 채널 연동(→ `pfId`) → API Key 발급
3. 아래 템플릿 4개를 솔라피 콘솔에서 등록하고 카카오 검수를 받습니다 (검수 기간이 있으니 미리 신청하세요).
   변수 이름은 코드와 **글자 하나까지 같아야** 합니다.

**TPL_APPLY — 신청 접수**
```
[비북스 b.moim] 신청 접수 안내

#{이름}님, 신청이 접수되었습니다.

■ 모임: #{모임명}
■ 일정: #{일정}
■ 신청번호: #{신청번호}
■ 입금액: #{금액}
■ 입금계좌: #{계좌}
■ 입금기한: #{기한}

입금이 확인되면 참가 확정 안내를 드립니다.
신청 확인·취소: #{확인링크}
```

**TPL_PAID — 참가 확정**
```
[비북스 b.moim] 참가 확정 안내

#{이름}님, 입금이 확인되어 참가가 확정되었습니다.

■ 모임: #{모임명}
■ 일정: #{일정}
■ 신청번호: #{신청번호}
■ 장소: 비북스 (부천로136번길 24 지하 B02호)

신청 확인: #{확인링크}
```

**TPL_RENT — 대관 접수**
```
[비북스] 대관 신청 접수 안내

#{이름}님, 대관 신청이 접수되었습니다.

■ 공간: #{공간}
■ 일정: #{일정}
■ 신청번호: #{신청번호}

담당자가 일정 확인 후 금액과 입금 방법을 안내드립니다.
신청 확인: #{확인링크}
```

**TPL_RESEND — 신청번호 재안내**
```
[비북스 b.moim] 신청번호 안내

#{이름}님의 신청 내역입니다.
#{신청목록}

신청 확인: #{확인링크}
```
> 링크는 검수 가이드에 따라 본문 대신 **웹링크 버튼**으로 등록하라는 요청을 받을 수 있어요. 그때는 버튼 URL을 `https://moim.bbooks.co.kr/v2/my/`로 고정하고 본문의 `#{확인링크}` 줄을 지운 뒤, `Code.gs`에서 그 템플릿에 넘기는 `'#{확인링크}'` 항목도 함께 지워 주세요 (템플릿과 변수 목록이 어긋나면 발송이 거절될 수 있어요).
>
> 다른 대행사(NHN Cloud, 알리고 등)를 쓰려면 `Code.gs`의 `sendAlimtalk_` 함수 하나만 바꾸면 됩니다.

4. 스프레드시트 메뉴 **비모임 ▸ 알림 발송 테스트**로 내 번호에 먼저 보내 보고, `발송로그` 탭에서 결과를 확인하세요.

## 6. 메일
별도 설정 없이 Apps Script(`MailApp`)로 발송됩니다. 보내는 계정은 스크립트를 배포한 구글 계정이고, 하루 발송 한도가 있습니다 (일반 Gmail 계정 100통/일 수준). 신청자가 이메일을 적은 경우에만 발송합니다.

## 7. 호스트 현황 링크
1. 스프레드시트 메뉴 **비모임 ▸ ② 호스트 현황 링크 발급**
2. 모임 slug 입력 (여러 개면 쉼표) — slug는 `data/moims.json`의 `"slug"` 값
3. 표시되는 링크(`…/host/dashboard/#k=긴열쇠`)를 호스트에게만 전달
- 열쇠는 40자 무작위 값이라 추측할 수 없습니다. (기존 `TOJI2026` 같은 코드는 공개 JS 파일에 들어 있어 누구나 볼 수 있었습니다)
- 중지: `호스트링크` 탭 `활성`을 `N`으로
- 기본은 이름 일부·연락처 뒷자리만 표시. 호스트가 직접 연락해야 하면 `연락처공개`를 `Y`로

## 8. 연결 후 점검 순서
- [ ] 페이지에서 테스트 신청 → `신청` 탭에 행 추가, 알림톡·메일 수신, 운영자 메일 수신
- [ ] `상태`를 `입금확인`으로 변경 → 확정 알림 수신
- [ ] 내 신청 확인 → 조회·취소 요청 → 상태 `취소요청`, 운영자 메일 수신
- [ ] 정원만큼 신청 → 페이지에 "모집 완료" 표시, 추가 신청 거절
- [ ] 대관 신청 → 같은 시간 재신청 시 거절
- [ ] 개설 신청 → `개설신청` 탭 + 운영자·호스트 메일
- [ ] 호스트 링크 → 현황 표시, 잘못된 열쇠는 거절
